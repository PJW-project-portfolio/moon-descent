Moon Descent 실행 방법 (Windows)

1. 받은 zip 파일을 마우스 오른쪽 버튼으로 클릭하고 "압축 풀기"를 선택하세요.
2. 압축을 푼 폴더를 열고 MoonDescent.exe를 더블클릭하면 게임이 시작됩니다.

처음 실행할 때 파란색 "Windows의 PC 보호" 창이 나타날 수 있습니다.
"추가 정보"를 누른 뒤 "실행"을 눌러 주세요.
개인이 만든 무료 게임이라 디지털 서명이 없어 표시되는 안내입니다.

백신 프로그램이 게임을 차단하면 백신 알림에서 "허용"을 선택해 주세요.

조작법

키                 기능
← / →              착륙선 회전
↑ 또는 Space       추진
P                  일시정지
R                  재시작
Esc                종료
Enter / Space      시작·다음

설치가 어렵다면 컴퓨터 브라우저에서 바로 플레이할 수 있습니다: https://pjw-project-portfolio.github.io/moon-descent/

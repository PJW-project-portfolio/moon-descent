# Moon Descent

1979년 아케이드 게임 감성으로 만든 Python/Pygame 기반의 2D 달 착륙 게임입니다.
제한된 연료로 착륙선의 자세와 속도를 제어해 표시된 착륙 지점에 안전하게
내려앉는 것이 목표입니다.

## 실행 환경

- Python 3.10 이상
- Pygame 2.5 이상

가상 환경 사용을 권장합니다.

```bash
cd lunar_lander_game
python3 -m venv .venv
source .venv/bin/activate
python -m pip install -r requirements.txt
python main.py
```

## 간편 실행과 배포

- **다른 사람에게 공유**: `./release.sh` 한 줄로 GitHub 클라우드에서 Windows/맥/리눅스 실행 파일 3종이 빌드되어 `release/`에 저장됩니다. 각 zip/tar.gz에는 상대방용 `실행방법.txt`가 동봉됩니다. 전달 방법은 아래 "카카오톡으로 보낼 파일 고르기"를 참고하세요.
- **최초 1회 준비물**: GitHub 계정, `gh auth login` 로그인, 공개 저장소(이미 설정되어 있음).

## 3D 버전 (Moon Descent 3D)

`web3d/` 폴더에 Three.js 기반의 3차원 착륙 시뮬레이션이 들어 있습니다.
6자유도(위치 3축 + 자세 3축) 물리로 움직이는 착륙선을 RCS(자세제어 추력기)와
메인 엔진으로 조종해, 달 표면에 초록색으로 표시된 착륙 패드에 내려앉는
게임입니다. 현재는 스테이지 1개만 제공합니다.

메인 화면(체이스 카메라) 외에 화면 하단에 방향별 카메라 3개가 함께 표시됩니다.

- **DOWN CAM**: 기체 바로 아래를 내려다보는 카메라 — 패드 정렬용 핵심 화면
- **FORWARD CAM**: 기체 전방 카메라 (수평선·자세 확인)
- **PAD CAM**: 착륙 패드 옆에 고정되어 착륙선을 추적하는 카메라

빌드나 설치 없이 정적 파일만으로 동작합니다(three.js 동봉). 로컬 실행:

```bash
python3 -m http.server 8000
# 브라우저에서 http://localhost:8000/web3d/ 접속
```

`?seed=숫자`를 주소에 붙이면 같은 지형을 재현할 수 있습니다.

웹 배포: 다음 `./release.sh` 실행(Pages 재배포) 이후에는
https://pjw-project-portfolio.github.io/moon-descent/3d/ 에서도 플레이할 수 있습니다.

### 3D 조작법

| 키 | 기능 |
|---|---|
| `W` / `S` (또는 `↑`/`↓`) | 피치 (앞/뒤 기울이기) |
| `A` / `D` (또는 `←`/`→`) | 롤 (좌/우 기울이기) |
| `Q` / `E` | 요 (좌/우 선회) |
| `Space` (누르고 있기) | 메인 엔진 |
| `X` | SAS(회전 자동 감쇠) 켜기/끄기 — 기본 켜짐 |
| `C` | 메인 카메라 전환 (체이스 ↔ 패드 고정) |
| `R` | 새 지형으로 재시작 |
| `Enter` | 시작 |

### 3D 착륙 조건

다리 4개가 모두 초록 패드(반경 15 m) 안에 닿아야 하며:

- 하강 속도 3 m/s 이하, 수평 속도 2 m/s 이하
- 기울기 12° 이내, 잔여 회전 0.35 rad/s 이하

중력은 실제 달과 같은 1.62 m/s²입니다. 연료는 메인 엔진과 RCS가 함께
소모하며, 남은 연료와 착지 부드러움에 따라 점수가 계산됩니다.

3D 로직 테스트는 Node.js로 실행합니다.

```bash
node --test web3d/tests/*.test.mjs
```

## 조작법

| 키 | 기능 |
|---|---|
| `←` / `→` | 착륙선 좌우 회전 |
| `↑` / `Space` | 주 추력기 작동 |
| `P` | 일시정지 / 계속 |
| `R` | 새 게임 |
| `L` | 리더보드 열기 / 스테이지 클리어 점수 기록 후 종료 |
| `Esc` | 종료 (리더보드 화면에서는 타이틀로 돌아가기) |
| `Enter` | 시작, 다음 스테이지 또는 결과 화면 넘기기 |

## 게임 규칙과 착륙 조건

착륙선 전체가 빛나는 평탄 지점 안에 있어야 하며, 다음 조건을 모두
만족해야 합니다.

- 수평 속도: 3.5 m/s 이하
- 하강 속도: 4.5 m/s 이하
- 기울기: 수직 기준 ±12° 이내

착륙 지점은 폭에 따라 `x2`부터 `x5`까지 점수 배율을 제공합니다. 폭이 좁을수록
배율이 높고, 스테이지가 진행될수록 착륙 지점도 좁아집니다.

게임은 실제 천체 표면 중력을 적용한 3개 스테이지로 구성됩니다.

- `MOON 1.62 m/s²` — 달: 검은 하늘과 별
- `MARS 3.71 m/s²` — 화성: 붉은 지형과 옅은 별
- `VENUS 8.87 m/s²` — 금성: 별이 보이지 않는 짙은 유황빛 대기

지형은 화면 다섯 개 너비로 생성되며 좌우 끝이 이어지는 무한 래핑 맵입니다.
카메라는 착륙선을 화면 중앙에 유지하며 수평 이동을 따라갑니다.

1~2단계에서 착륙하면 스테이지 클리어 화면에서 선택합니다. `Enter`를 누르면
다음 천체로 계속 진행하고, `L`을 누르면 현재 점수를 기록하고 임무를 종료합니다.
마지막 `VENUS` 착륙은 임무 완수로 처리되어 점수가 자동 기록됩니다.

다음 스테이지로 진행할 때 기본 연료를 100% 보충하고 시간 보너스 연료를 더합니다.
보너스는 기준시간보다 빠른 초당 0.6, 최대 30이며 연료 용량을 초과할 수 있습니다.
기준시간은 `MOON 45초`, `MARS 50초`, `VENUS 60초`입니다.

착륙선은 모든 스테이지와 재시도에서 수평·수직 속도 0으로 시작합니다.
1단계에서 추락하면 연료를 100% 보충받습니다. 2단계부터는 시간 보너스를 포함해
해당 단계에 처음 진입했을 때의 연료량으로 복원하고 동일한 지형에서 재시도합니다.

리더보드는 점수, 도달 천체, 날짜를 상위 10개까지 저장합니다. 데스크톱 빌드에서는
로컬 파일에 계속 보존되고, 웹 빌드에서는 브라우저 실행 세션 동안만 유지됩니다.

게임 전체에 목숨 3개가 주어지며 스테이지가 바뀌어도 다시 채워지지 않습니다.
추락할 때마다 하나씩 잃고, 세 번째 추락 시 현재 점수가 자동 기록된 뒤 게임이
종료됩니다.

## 테스트

Pygame 창을 띄우지 않는 핵심 로직 테스트입니다.

```bash
python -m unittest discover -s tests -v
```

헤드리스 환경에서 게임 초기화까지 확인하려면 다음 명령을 사용할 수 있습니다.

```bash
SDL_VIDEODRIVER=dummy python -c "from lunar_lander.app import LunarLanderApp; app = LunarLanderApp(seed=1); app._draw()"
```
